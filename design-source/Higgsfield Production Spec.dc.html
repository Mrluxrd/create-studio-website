Higgsfield production specification · v2.0

Sixteen artwork positions, one connected narrative.

Every position below exists in the built website as a neutral placeholder reserving its final dimensions. Higgsfield creates the artwork and its internal movement; Claude Design controls layout, reveals, masks, container scaling and responsive behavior. No artwork is generated in Claude Design.

Narrative sequence

Idea → Structure → Transformation → Connection → Identity → Growth → Stability → Launch → New Beginning

The sequence governs placement, focal point, crop and integration only.

Shared constraints

Background true #09090B. Colour limited to #2563FF → #8B5CF6. Consistent grain across every asset. No readable text or numerals inside artwork. No glassmorphism, cubes, data nodes, fake interfaces or generic technology imagery. Loops 12–20s unless stated. Reduced-motion users receive the static fallback.

Delivery

/artwork/[asset]-[breakpoint].[ext]
Every animated asset ships with a poster frame at t=0 for first paint and reduced motion. Budget: 4.5 MB desktop, 1.8 MB mobile; hero and contact up to 1.2 MB each, all others 400 KB or less.

Integration notes

Placeholders reserve their media box, so replacing them causes no layout shift. Decorative loops autoplay muted, pause offscreen and fall back to the poster under prefers-reduced-motion. Only the homepage hero loads with priority.
